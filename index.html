Cafe details

Token counter setup

Choose which menu categories print on each counter token. You can add a Chaat Counter or any future counter here.

Enter category names separated by commas, matching the Category field in Items & Prices. Print order: customer bill, then each configured counter token. Counters with no matching items are skipped.

Menu category settings

Manage your menu categories here. Add a category once and it will be available in Add Item and the category filters. These categories will be available when adding or editing items, and will appear as filters above the item list.

Data backup

Export all menu items, bills, expenses and settings to a JSON backup. Store it somewhere safe. Importing a backup replaces the current records on this device.
